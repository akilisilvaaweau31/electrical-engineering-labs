# Electrical Engineering Labs

This repository documents my Electrical Engineering training and portfolio work as it develops. It is intended to hold organized lab notes, circuit analysis, simulations, code, embedded experiments, digital logic work, PCB design practice, and project documentation.

## Purpose

The purpose of this repository is to keep my engineering work version controlled, readable, and suitable for long-term review. It should show how I approach problems, document assumptions, test designs, and improve through feedback and error tracking.

## Current Training Phase

This repository is in the foundation-building phase. The current focus is setting up a clean workspace for circuits, C programming, LTspice simulations, embedded systems, digital logic, PCB design, and project documentation.

## Repository Structure

## Engineering Workflow

Work in this repository should follow a clear engineering flow:

1. Define the objective and constraints.
2. Record assumptions, given values, and references.
3. Analyze or design the system before building.
4. Simulate where appropriate.
5. Implement the circuit, code, or prototype.
6. Test against expected behavior.
7. Document results, mistakes, fixes, and next steps.

## Projects

Projects will be added as they are started. Each project should include its own README with the objective, tools used, design notes, source files, test evidence, and lessons learned.

## Documentation Standard

Each meaningful lab, exercise, or project should include enough context for a future reader to understand what was attempted, how it was tested, and what was learned. Documentation should avoid unsupported claims and should distinguish between planned work, in-progress work, and completed results.
