# Templates

Copy only the template you need into the actual project directory. Replace prompts with your own content and remove irrelevant sections. Keep unperformed work marked pending.

| Need | Template |
| --- | --- |
| Analyze, simulate, or measure a circuit/system | [Lab record](lab/README.md) |
| Record raw observations | [Measurements CSV](lab/measurements.csv) |
| Track uncertainty contributors | [Uncertainty CSV](lab/uncertainty-budget.csv) |
| Start a C/C++ project with reproducible instructions | [C++ project](cpp-project/README.md) |
| Organize a SPICE experiment | [SPICE project](spice-project/README.md) |
| Start a board-specific firmware project later | [Firmware project](firmware-project/README.md) |
| Document components and connections | [Hardware record](hardware/README.md) |
| Explain a finished or substantial project to a reviewer | [Case study](case-study.md) |
| Collect facts for a résumé bullet | [Résumé evidence](resume-evidence.md) |
| Record an engineering choice | [Decision record](decision-record.md) |
| Preserve a useful source and its limits | [Research note](research-note.md) |
| Leave the next session a clear starting point | [Session handoff](session-handoff.md) |
| Explain substantial AI assistance | [AI assistance](ai-assistance.md) |

The CSV files intentionally contain headers only. They are empty forms, not experimental data. Each copied template should identify the real project, date, evidence type, and author/contributor role.
