# Hardware record

Use this with an actual circuit or board. It does not imply that hardware has been purchased, assembled, or tested.

## Design files

Identify the authoritative schematic/layout, software version, component library origin, and board revision. Keep editable source alongside selected PDF/image exports when the exports help reviewers.

## Components

Fill in [bom.csv](bom.csv) with exact parts when selected. Record alternatives as alternatives, not as the installed part. Distinguish estimated prices from actual purchase prices and include a date/currency for any cost claim.

## Connections

Fill in [pin-map.csv](pin-map.csv). Include the reference node/ground, direction, voltage domain, and signal purpose. Check the selected part and board revision against manufacturer documentation.
